# LD-TM — Logic Driven · Technology Masters

**Tagline:** Turning Ideas into Intelligence.

A responsive agency website for AI-powered web apps, custom web development, AI assistants, workflow automation, SaaS MVPs and website development.

## Files
- `index.html` — complete single-page website and enquiry form
- `styles.css` — responsive visual system and layout
- `script.js` — mobile navigation, footer year and email-draft form behavior

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish the site; the public URL will appear in the Pages settings.

## Enquiry form status
The current form performs browser-side validation and opens a pre-filled email draft using the visitor's email app. It does **not** send email automatically or store enquiries in a database. Configure a trusted form service or secure backend before relying on it for customer lead collection.
